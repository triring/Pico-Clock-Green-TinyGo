# Pico-Clock-Green TinyGo ストップウォッチ

Waveshare Pico-Clock-Green 用の、シンプルなストップウォッチです。

## 仕様

- 表示: `mm:ss`
- 最大計測時間: `99:59`
- RTC: 使用しません
- スタート／ストップ: `GP2`
- リセット: `GP15`
- ブザー: `GP14`
- 通知音: `1980 Hz`
- 電源投入時: `00:00`
- 99:59 に到達すると自動停止します。
- スタートせずに1分以上待機すると、`config.go` の `standbyScrollText` をスクロール表示します。
- スクロール間隔は `config.go` の `standbyScrollInterval` で変更できます。
- スクロール文字列は `scrollTextBufferSize`（2048バイト）のバッファに保持します。
- スクロール表示中にスタートボタンを押すと、直ちに計測を開始します。
- スクロール表示が終わると、通常の `00:00` 表示に戻ります。

## 操作と通知音

| ボタン | 操作 | 通知音 |
|---|---|---|
| GP2 | 停止中に1回押すと計測開始 | 1980 Hz / 0.05 秒 |
| GP2 | 計測中にもう1回押すと一時停止 | 1980 Hz / 0.1 秒 |
| GP2 | 一時停止中にもう1回押すと停止位置から再開 | 1980 Hz / 0.1 秒 |
| GP15 | `00:00` にリセット | 1980 Hz / 0.5 秒 |

リセットすると計測は停止し、表示と内部カウンタの両方が 0 になります。

リセット音については、JIS S 0013 にリセットという操作専用の音が定義されていないため、終了音相当として 0.5 秒に設定しています。

## 通知音の実装

通知音には TinyGo の `tinygo.org/x/drivers/tone` パッケージを使用しています。
このドライバは PWM を利用して音を生成し、`Speaker.SetPeriod()` で周波数を指定できます。

RP2040 では GP14 が PWM7 のチャンネル A に対応しているため、GP14 のブザーには `machine.PWM7` を使用しています。

周波数は、高齢者にも音が聞き取り易い2KHz近辺の音として、6オクターブのシ(1980 Hz)に設定しました。`tone` ドライバでは周期をナノ秒で指定するため、`1e9 / 1980` で設定する周期を求めています。

## 実装上の特徴

ブザー音の再生は専用 goroutine で行います。そのため、0.5 秒や 1.0 秒の停止音・リセット音が鳴っている間も、ストップウォッチ本体の処理を停止させません。
短時間に複数回の操作が行われた場合は、通知音を無制限にキューへ蓄積しないようにしています。

## 実装方針

このプログラムでは 内蔵されているDS3231 RTC を一切使用していません。
計測中は `time.Now()` を利用して実際の経過時間を求めています。10 ms 周期で計測状態を確認し、前回処理時刻との差から経過秒数を計算するため、単純に「1秒ごとにカウンタを1増やす」方式よりも、タイマー処理の遅延が累積しにくい構成になっています。

## ファイル構成

| ファイル | 機能 |
|---|---|
| `main.go` | メインループ、タイマー処理、ブザー初期化 |
| `config.go` | GPIO 定義、スクロール設定、表示バッファ定義 |
| `app.go` | ストップウォッチの状態・計測・表示・通知音制御 |
| `input.go` | GP2 / GP15 のボタン入力処理 |
| `buzzer.go` | GP14 のブザー制御、通知音の定義 |
| `display.go` | LED マトリクスのリフレッシュ、通常表示、スクロール表示制御 |
| `font.go` | 4×7 ドットフォント |

## ビルド例

以下のコマンドを実行すると、コンパイル後、Pico-Clock-Greenに実行ファイルを転送します。  

```text
tinygo flash -target=pico --size short .
```

また、実行用バイナリをうまく転送できない場合は、以下のコマンドで、実行用バイナリを生成して、手作業でPico-Clock-Greenに転送して下さい。  

```text
tinygo build -target=pico -o Stopwatch.uf2 --size short .
```
