# Pico-Clock-Green TinyGo

[waveshare](https://www.waveshare.com/)の[Pico-Clock-Green](https://www.waveshare.com/wiki/Pico-Clock-Green)というLEDクロック用、C++で書かれたサンプルが公開されています。 これをAIさんの力を借りながら、tinygoで書き換えました。  

オリジナルは、内蔵のRTCを使用して時刻を刻み、アラームやタイマーの機能を持っていました。しかし、RTC機能を使うと以下のような不具合が発生し、どうしても修正することが出来ず実装を諦めました。  

* RTCのバックアップ機能が正常に動かない。
* RTCへの時刻設定中に設定が0になり、それ以降、設定作業ができなくなる。

そこで、基本機能に絞って、ソフトウェアのみで以下の実装しました。

* 時刻設定と表示
* Beep音のOn/Off
* スクロール表示のOn/Off
* 12/24時間表示の切替
* 時報のOn/Off

## 1. 概要

本プログラムは、[waveshare](https://www.waveshare.com/)  **[Pico-Clock-Green](https://www.waveshare.com/wiki/Pico-Clock-Green)** を Raspberry Pi Pico + TinyGo で動作させるための時計アプリケーションです。

この版を、実機で仕様どおりの動作を確認した**最終版（v12 dayfix）**とします。

[Pico-Clock-Green](https://www.waveshare.com/wiki/Pico-Clock-Green)には、RTC（DS3231）が搭載されていますが、いくつかの不具合があったためこれを使用せず、Raspberry Pi Pico 上でソフトウェア時計として動作させます。そのため、電源を切ってしまうと時刻は保持されません。

時刻・日付の設定順は次のとおりです。

**年 → 月 → 日 → 時 → 分 → Beep → スクロール → 12/24時間 → 時報**

最後の「分」を SET で確定した瞬間に、**秒は 00 秒**に設定されます。

## 3. ソースコードについて

[tinygo_clock](./tinygo_clock)ディレクトリ内のソースコードを参照して下さい。

``` bash
> tree /a /f

\---tinygo_clock
        go.mod
        main.go
        config.go
        app.go
        input.go
        display.go
        font.go
```


### ソースファイル構成

| ファイル | 主な役割 |
|---|---|
| `main.go` | ハードウェア初期化、メインループ、周期処理 |
| `app.go` | 時計状態、設定モード、時刻・日付設定、各種設定値の管理 |
| `input.go` | SET / UP / DOWN ボタンの入力処理 |
| `display.go` | LED表示制御、文字表示、点滅・スクロールなどの表示処理 |
| `font.go` | 7ドット高フォントの定義 |
| `config.go` | Pico-Clock-Green のGPIO等のハードウェア設定 |
| `go.mod` | Go / TinyGo プロジェクト設定 |

### フォント構造

`font.go` のフォントは、文字を直接検索できる map 構造になっています。

概念的には次のような構造です。

```text
文字
 ↓
Glyph
 ↓
7行分のドットデータ
```

従来の1次元配列＋文字比較用 `switch` 方式ではなく、文字から Glyph を直接取得できる構造になっています。

## 4. プログラムのコンパイルと転送について

### ソースコードの入手

以下のコマンドで、このサイトの内容をローカルドライブにコピーして下さい。  

```bash
> git clone https://github.com/triring/Pico-Clock-Green-TinyGo.git
```

### コンパイルと転送

まず、開発用PCとPico-Clock-GreenをUSBケーブルで接続して下さい。  
次に、tinygo_clockディレクトリにに移動して、以下のコマンドを実行して下さい。  
コンパイルが完了すると、生成した実行用バイナリはzero-kb02に転送されます。  

```bash
> cd tinygo_clock
> tinygo flash -target=pico -size=short .
   code    data     bss |   flash     ram
  41688     888    6116 |   42576    7004
```

また、実行用バイナリを転送できない場合は、以下のコマンドで、実行用バイナリを作成し、手作業で、実行用バイナリをPico-Clock-Greenに転送して下さい。  

```bash
> cd tinygo_clock
> tinygo build -o tinygo_clock.uf2 --target pico --size short .
   code    data     bss |   flash     ram
  41688     888    6116 |   42576    7004
> dir *.uf2
-a----        2026/09/21     22:01          85504 tinygo_clock.uf2
```

## 5. ボタン操作

4つの操作ボタンを使用します。

| ボタン | 通常表示 | 設定モード |
|---|---|---|
| SET | 設定モードへ移行（長押し） | 次の設定項目へ |
| UP | 基本的に機能なし | 値を増加 |
| DOWN | 基本的に機能なし | 値を減少 |
| SET（長押し） | 設定モードへ移行 | 設定モードでの項目確定・次項目へ |

### ボタン入力時間

| 押下時間 | 判定 |
|---|---|
| 50 ms 未満 | 無視 |
| 50 ms ～ 300 ms 未満 | 短押し |
| 300 ms 以上 | 長押し |

長押しは、押し続けている間に何度も実行されないように処理されています。

## 6. 時刻・日付の設定

設定モードへ入ると、次の順番で設定します。

### 6.1 設定順

1. 年
2. 月
3. 日
4. 時
5. 分
6. Beep
7. スクロール表示
8. 12/24時間表示
9. 時報

各項目では UP / DOWN で値を変更し、SET で次の項目へ進みます。

### 6.2 年

UP / DOWN で年を変更します。

年の変更によって現在の日付が存在しなくなる場合は、月末日に自動調整されます。

例えば、うるう年の 2 月 29 日から、うるう年ではない年へ変更した場合は、2 月 28 日へ調整されます。

### 6.3 月

UP / DOWN で月を変更します。

変更後の月に現在の日が存在しない場合は、その月の最終日に自動調整されます。

例えば、

- 3月31日 → 4月

と変更した場合、4月には31日がないため、

- 4月30日

へ自動調整されます。

### 6.4 日

UP / DOWN で日を変更します。

その年月に存在する日数を超えないように制御されています。

### 6.5 時

UP / DOWN で時を変更します。

表示形式が12時間表示の場合でも、内部の時計値は通常の24時間形式で管理されます。

### 6.6 分

UP / DOWN で分を変更します。

分の設定を終えて SET を押すと、その瞬間に

**秒 = 00**

として時刻が確定します。

例えば、

> 09:25:47

を設定して、分を 26 にして SET を押した場合、

> **09:26:00**

として確定します。

これにより、分単位で時刻を設定した際に最大約30秒ずれる問題を避けています。

## 7. 日付の妥当性チェック

日付は単純に「1～31」の範囲だけではなく、年月に応じた正しい日数でチェックされます。

### 月の日数

| 月 | 日数 |
|---|---:|
| 1月 | 31 |
| 2月 | 28 または29 |
| 3月 | 31 |
| 4月 | 30 |
| 5月 | 31 |
| 6月 | 30 |
| 7月 | 31 |
| 8月 | 31 |
| 9月 | 30 |
| 10月 | 31 |
| 11月 | 30 |
| 12月 | 31 |

### うるう年

次のルールで判定します。

- 400で割り切れる年 → うるう年
- 100で割り切れる年 → うるう年ではない
- 4で割り切れる年 → うるう年
- それ以外 → うるう年ではない

例えば、

- 2024年 → うるう年
- 2100年 → うるう年ではない
- 2000年 → うるう年

となります。

## 13. ソフトウェア時計について

本プログラムではいくつかの不具合は発生したため、DS3231 RTC を使用していません。  

電源投入後はプログラムに設定された初期日時からソフトウェア時計を開始し、その後は 1 秒ごとに時刻を進めます。  

従って、 **電源を切る → 再度電源を入れる** という操作を行った場合、電源断前の時刻は保持されません。  

---

## 14. 高速ボタン入力への対策

過去の版では、ボタンを短時間に連続して操作した場合に、設定値が 0 になるなどの問題が発生しました。  
そこで、ボタン入力をメイン処理ループ側で処理する構造に変更しています。  
これにより、時計状態と入力処理が別々の処理から同時に変更される問題を避けています。  
また、時刻・日付を変更する際には、変更後の値が正しい日時であることを確認してから `a.now` を更新する構造になっています。  
実機テストでは、高速なキー入力を行っても設定不能になる問題が解消されています。

## 15. ハードウェア接続

Pico-Clock-Green の主要なGPIO割り当ては次のとおりです。

| 機能 | RP2040 GPIO |
|---|---:|
| LED OE | GP13 |
| LED SDI | GP11 |
| LED CLK | GP10 |
| LED LE | GP12 |
| A0 | GP16 |
| A1 | GP18 |
| A2 | GP22 |
| SET | GP2 |
| I2C SDA | GP6 |
| I2C SCL | GP7 |
| UP | GP17 |
| DOWN | GP15 |
| Buzzer | GP14 |
| Light ADC | GP26 / ADC0 |

RTCを使用しない最終版では、DS3231 の SQW 信号を時計処理には使用しません。  
また、TinyGo では GP29 を直接 `machine.GP29` として扱えないため、過去の互換コードでは GP29/ADC3 を `machine.ADC3` として扱っていました。

## 18.仕様のまとめ

本バージョンの基本コンセプトは、**Pico-Clock-Green を大きな時計表示としてシンプルに使用すること**です。  

設定操作は、

```text
SET長押し
   ↓
年
   ↓
月
   ↓
日
   ↓
時
   ↓
分
   ↓
Beep
   ↓
スクロール
   ↓
12/24時間
   ↓
時報
```

という順番です。  

特に時刻設定では、最後の「分」を SET で確定した時点を基準として、

```text
時：分：00
```

となります。
