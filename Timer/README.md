# Pico-Clock-Green TinyGo カウントダウンタイマー

Waveshare Pico-Clock-Green を Raspberry Pi Pico + TinyGo で動かすカウントダウンタイマーです。

RTC / DS3231 は使用せず、Pico の CPU 上で経過時間を管理します。

## 表示

- `mm:ss`
- 最大 `99:59`
- カウントダウン終了後は `00:00`

## GPIO

| 機能 | GPIO |
|---|---:|
| MODE | GP2 |
| UP | GP17 |
| START/STOP | GP15 |
| ブザー | GP14 |

## 待機中のスクロール表示

- 起動直後やタイマー停止後など、キー入力待ちの状態で1分以上入力がないと、`config.go` の `standbyScrollText`（初期値 `COUNT DOWN`）をスクロール表示します。
- スクロール文字列の表示が最後まで終わると、通常のキー入力待ちに戻り、現在のタイマー値を表示します。
- スクロール表示中に MODE / UP / START/STOP のいずれかを押すと、スクロールだけを中断してキー入力待ちに戻ります。中断に使用したボタンの通常操作は実行しません。
- スクロール文字列とスクロール間隔は `config.go` で変更できます。

## 操作

### MODE

- 長押し（500ms）：設定モードへ入る／設定モードから抜ける
- 設定中の短押し：設定対象を `10分台 → 1分台 → 10秒台 → 1秒台 → モード終了` の順に切り替える
- 設定中の対象桁は点滅します。
- カウントダウン中の MODE 長押しは無視します。

### UP

- 設定中の短押し：選択桁を +1
- 上限を超えると 0 に戻ります。
- 長押し：500ms 後から100ms間隔で連続加算します。

### START/STOP

- 短押し：開始／停止／再開
- 長押し（500ms）：記憶している設定時間へリセット

起動直後は `00:00` です。MODEで時間を設定して終了すると、その値を「設定時間の初期値」として記憶します。

## カウントダウン終了時

`00:00` になると JIS S 0013:2022 の終了音（近）(4)に準じた音を10回繰り返します。

- `buzzerFrequency` / 100ms
- 無音 / 100ms
- `buzzerFrequency` / 500ms
- 無音 / 500ms

終了音中にいずれかのボタンを押すと、終了音だけを停止し、記憶している設定時間を表示したキー入力待ち状態になります。中断に使用したボタンの通常操作は実行しません。

## 設定値

操作感を調整する可能性のある時間値は `config.go` に `const` としてまとめています。

- 長押し判定：500ms
- UP連続加算：100ms
- 設定桁点滅：250ms
- MODE桁切替：50ms
- MODE短押しによる終了：500ms
- MODE長押しで入る：100ms
- MODE長押しで抜ける：300ms
- UP短押し：50ms
- START：50ms
- STOP：100ms
- START/STOP長押しリセット：1000ms
- 待機スクロール開始：1分
- 待機スクロール間隔：50ms

ブザー周波数は `buzzer.go` の `buzzerFrequency = 1980` を使用します。
